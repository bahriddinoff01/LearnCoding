# LearnCoding

Learn HTML, CSS, JavaScript, Python and React by building. Every section has lessons with live examples, exercises, quizzes, a challenge, and a final project you build on your own with an AI instructor that gives hints, not answers.

**Live site:** https://bahriddinoff01.github.io/LearnCoding/

## Features so far
- Home page and track catalog
- HTML track with 4 lessons in 2 sections
- Lesson page with a VS Code-style editor (Monaco), live preview, and automatic checks
- Progress saved in the browser

## Roadmap
- Quizzes, section challenges and final projects
- AI instructor with step-by-step hints
- Accounts and saved progress (Supabase)
- CSS, JavaScript, Python, React and SQL tracks

## Tech stack
React, TypeScript, Vite, Tailwind CSS, React Router, Monaco Editor, Supabase. Deployed to GitHub Pages with GitHub Actions.

## Run locally
```bash
npm install
npm run dev
```
